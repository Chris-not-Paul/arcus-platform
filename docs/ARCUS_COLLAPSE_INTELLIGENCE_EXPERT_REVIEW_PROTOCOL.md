## Objective

Prepare a blind expert-review package comparing:

- baseline hazard-gated cohort output;
- ARCUS project-informed retrieval output.

The package does not simulate expert responses.

## Sampling Policy

The package includes:

- 10 hydraulic cases where available;
- sufficiently complete landslide cases;
- sufficiently complete seismic cases;
- multi-hazard cases when active;
- evidence-insufficient cases where available.

Current package size: 19 cases.

## Blind Output Design

For each case, outputs are anonymized as:

```text
A
B
```

The reviewer should not know which output is ARCUS retrieval.

## Scoring Schema

Each case should be reviewed on:

- relevance of analogues;
- engineering similarity;
- usefulness of failure patterns;
- usefulness of investigation priorities;
- misleading content;
- missing critical information;
- preference A/B/tie.

## Governance

Mitigation and investigation outputs remain draft unless external engineering basis or documented expert review exists.

No mitigation should be presented as automatically appropriate for the single site.
