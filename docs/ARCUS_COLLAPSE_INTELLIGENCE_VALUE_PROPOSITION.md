# ARCUS Collapse Intelligence - Value Proposition

This document explains the difference between consulting public portals and using ARCUS Professional. It avoids unproven commercial claims.

## Baseline A - Public Hazard Only

Input:

- ISPRA hydraulic;
- ISPRA PAI landslide;
- INGV MPS04 seismic.

Output:

```text
Official exposure description for the selected site.
```

Limit:

It does not explain how similar contexts have appeared in documented bridge collapses.

## Baseline B - Public Hazard + General HCI

Input:

- public hazard layers;
- general provincial Historical Collapse Incidence.

Output:

```text
Official exposure plus province-level historical incidence.
```

Limit:

It does not identify cause-specific patterns or analogue outcomes.

## Baseline C - ARCUS Collapse Intelligence

Input:

- official site hazard signature;
- cause-specific historical evidence;
- analogue cohort;
- failure pattern taxonomy;
- evidence strength;
- draft mitigation knowledge model.

Output:

```text
Documented analogue patterns, limitations, evidence strength and priority investigation themes.
```

## Demonstrative Difference

Public hazard:

```text
Hydraulic P3.
```

ARCUS intelligence, once validated:

```text
Hydraulic P3 plus documented analogue cohort; recurring patterns in compatible cases; source-linked evidence limitations; priority investigation themes such as hydraulic modelling, scour assessment and access-vulnerability review.
```

This example is not production output.

## Where ARCUS Adds Value

- connects official hazard to documented collapse evidence;
- shows analogue case IDs and source strength;
- separates hazard, historical evidence and confidence;
- identifies recurrent patterns rather than only map classes;
- supports mitigation discussion through auditable evidence.

## Where Evidence Is Insufficient

ARCUS must abstain when:

- too few analogues exist;
- effective evidence count is low;
- outcomes are mostly unspecified;
- project profile fields are missing;
- source quality is weak;
- the cohort is dominated by one territory or one event.
